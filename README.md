#### 4º Semestre
**Em 2025-1** participei do desenvolvimento de um sistema de alertas ambientais baseado em IoT, cujo objetivo era monitorar variáveis como chuva, umidade e temperatura utilizando sensores físicos conectados a uma arquitetura publisher–subscriber. O dispositivo IoT publicava dados continuamente, enquanto o sistema recebia, processava e exibia essas informações em tempo real. O backend foi implementado com FastAPI e o frontend desenvolvido em React utilizando a biblioteca MUI, permitindo uma interface moderna e responsiva para visualização dos alertas. [Repositório](https://github.com/Code-Nine-FTC/API-2025.1)
- **Tecnologias Utilizadas:** FastAPI, Python, React, MUI, MQTT (publisher–subscriber), JavaScript, Docker
- **Contribuições Pessoais:** Atuei na implementação dos CRUDs essenciais para o gerenciamento de sensores, alertas e usuários, garantindo a integração eficiente entre o backend e o frontend.
- **Hard Skills Efetivamente Desenvolvidas:** APIs assíncronas com FastAPI, arquitetura distribuída com MQTT, integração IoT–sistema, React com Material UI
- **Soft Skills Efetivamente Desenvolvidas:** O trabalho com IoT exigiu comunicação constante com o time para alinhar hardware e software, além de adaptação rápida a problemas típicos de integração física, como instabilidade de sensores. Essa experiência fortaleceu minha capacidade de resolver problemas em ambientes reais, colaborar em múltiplas frentes do projeto e lidar com desafios técnicos que dependiam da cooperação entre áreas diferentes.

### Iniciação científica
**Em 2024-2**  Desenvolvi uma pesquisa acadêmica focada no monitoramento e análise da qualidade do ar, utilizando dados ambientais para estudar os níveis de poluentes atmosféricos e suas implicações. O projeto foi fundamentado em dados reais, abordando metodologias de análise e a aplicação de técnicas computacionais para classificar e visualizar os resultados.
- **Tecnologias Utilizadas:** Javascript, QGIS, CAMS Data Store, MySQL, KNN
- **Contribuições Pessoais:**
  - Desenvolvi algoritmos para processar e analisar dados de poluentes como CO, O₃, PM10 e PM2.5.
  - Integrei técnicas de machine learning, como KNN, para classificar a qualidade do ar com base em diferentes combinações de poluentes.
  - Usei ferramentas de geoprocessamento (QGIS e CAMS) para mapear e visualizar concentrações de poluentes em regiões específicas.
  - Modelei o banco de dados para armazenar e organizar os dados processados.
- **Hard Skills Efetivamente Desenvolvidas:** Processamento de dados ambientais, uso de ferramentas GIS, machine learning, processamento de imagem
- **Soft Skills Efetivamente Desenvolvidas:** O projeto sobre qualidade do ar foi uma oportunidade para desenvolver habilidades de organização e autonomia. Lidar com grandes volumes de dados exigiu planejamento cuidadoso para estruturar as informações e definir prioridades, enquanto a condução independente do projeto reforçou minha capacidade de tomar decisões e resolver problemas de forma proativa. Comunicar os resultados por meio de relatórios e apresentações foi essencial para aprimorar minha clareza na transmissão de ideias, especialmente ao adaptar conceitos técnicos para públicos diversos. A análise dos dados também fortaleceu meu pensamento crítico, permitindo identificar padrões e propor interpretações fundamentadas.

### Estágio no INPE – Monitoramento da Qualidade do Ar
Desde Janeiro de 2025 atuo como estagiária no Instituto Nacional de Pesquisas Espaciais (INPE), trabalhando no desenvolvimento de microsserviços voltados à disponibilização e análise de dados de qualidade do ar. O trabalho envolve lidar com poluentes atmosféricos provenientes de redes de monitoramento, sensores e modelos ambientais, integrando dados heterogêneos em pipelines automatizados. Também contribuo para análises computacionais e para o desenvolvimento de algoritmos que tratam, classificam e organizam informações ambientais usadas por pesquisadores e instituições públicas.
- **Tecnologias Utilizadas:** Python, Flask, JavaScript, Docker, PostgreSQL, QGIS, CAMS Data Store, machine learning
- **Contribuições Pessoais:** Desenvolvo microsserviços para publicação de informações ambientais, participo da modelagem e organização de dados de qualidade do ar, implemento rotinas de limpeza e análise, além de colaborar na estruturação de pipelines que padronizam e automatizam fluxos internos.
- **Hard Skills Efetivamente Desenvolvidas:** Arquitetura de microsserviços, processamento de dados ambientais, integração com bancos complexos, desenvolvimento de APIs especializadas
- **Soft Skills Efetivamente Desenvolvidas:** O estágio fortaleceu minha autonomia, responsabilidade e capacidade de resolver problemas técnicos em ambientes reais. Aprendi a comunicar resultados de forma clara para públicos técnicos e não técnicos, além de colaborar com pesquisadores e profissionais de áreas diversas, o que ampliou minha visão interdisciplinar e meu compromisso com aplicações tecnológicas de impacto social.
